MERCARI PRACTICAL GUIDE / 03

写真で「欲しい」を
伝える見せ方

見やすい写真で商品の魅力を届ける
01 / POINT

最初の1枚を大切に

商品全体が分かる写真を最初に設定します 背景を整えて主役をはっきり見せましょう

02 / POINT

明るさと背景

自然光が入る場所で撮影する 背景はシンプルに整える 色味が実物から離れないようにする

03 / POINT

撮影する角度

正面と背面と側面 ブランドタグやサイズ表示 傷や汚れのある部分を撮影します

04 / POINT

ジャンル別のポイント

洋服は形と丈感が伝わるように 靴は左右と靴底と内側も 雑貨は大きさと付属品が分かるように

05 / POINT

最後の確認

写真の順番を見直し 暗さやピンぼけがないか確認します
